راهنمای نصب صفر تا صد «VPN Panel + وی پی ان من»
نسخه عمومی 1.0.2
طراحی و توسعه: امید
============================================================

این بسته شامل دو بخش است:

01-vpn-panel-php
    پنل PHP/MySQL برای نگهداری لینک‌های Subscription، استخراج سرورها، API اپ، تبلیغات و تنظیمات.

02-vpn-man-android
    پروژه اپ اندروید فارسی «وی پی ان من» + GitHub Actions برای ساخت APK بدون Android Studio روی کامپیوتر شما.

مهم:
- هیچ لینک VPN واقعی، Subscription URL، دامنه شخصی، App API Key، Cron Token یا Admin Gate در این بسته قرار داده نشده است.
- مقادیر امنیتی را فقط روی نصب شخصی خودتان ایجاد کنید.
- این پروژه را فقط مطابق قوانین محل زندگی و شرایط سرویس‌دهندگان خود استفاده کنید.

============================================================
بخش اول — چیزهایی که نیاز دارید
============================================================

1) هاست لینوکسی با PHP 8.1 یا بالاتر
2) MySQL یا MariaDB
3) SSL/HTTPS فعال
4) افزونه‌های PHP زیر:
   pdo_mysql
   curl
   json
   openssl
   fileinfo
5) یک دامنه، ساب‌دامنه یا پوشه HTTPS برای پنل
6) حساب GitHub برای ساخت APK

پیشنهاد:
بهتر است پنل را روی ساب‌دامنه‌ای جدا از وردپرس نصب کنید تا PHP و مسیرهای سایت اصلی با آن تداخل نداشته باشند.

============================================================
بخش دوم — نصب VPN Panel روی هاست
============================================================

مرحله 1: ساخت دیتابیس
----------------------
در cPanel وارد Database Wizard شوید.

- یک Database بسازید.
- یک Database User بسازید.
- User را به Database متصل کنید.
- گزینه ALL PRIVILEGES را فعال کنید.

این چهار مقدار را نگه دارید:
DB Host    معمولاً localhost
DB Name
DB User
DB Password

مرحله 2: آپلود فایل‌های پنل
---------------------------
وارد File Manager هاست شوید.
پوشه `01-vpn-panel-php` را باز کنید و **محتویات داخل آن** را در مسیر مقصد آپلود کنید.

مثال نصب روی ساب‌دامنه:
public_html مربوط به vpn.example.com

مثال نصب داخل پوشه:
public_html/vpn/

نباید یک پوشه اضافه ایجاد شود؛ فایل `index.php` و پوشه‌های `admin`, `api`, `install` باید مستقیم در ریشه مسیر نصب باشند.

مرحله 3: اجرای نصب‌گر
----------------------
در مرورگر باز کنید:

https://YOUR-DOMAIN/YOUR-PATH/install/

مثال:
https://vpn.example.com/install/
یا:
https://example.com/vpn/install/

فیلدها را وارد کنید:

DB Host
DB Name
DB User
DB Password
نام کاربری مدیر
رمز مدیر — حداقل 10 کاراکتر
Base URL

Base URL باید دقیقاً مسیر نصب باشد و بهتر است / آخر نداشته باشد.
نمونه:
https://vpn.example.com
یا:
https://example.com/vpn

مرحله 4: ذخیره اطلاعات امنیتی
-----------------------------
بعد از نصب سه مقدار فقط یک بار نمایش داده می‌شوند:

App API Key
Cron Token
Admin Gate

هر سه را در جای امن ذخیره کنید.

کاربرد آنها:
App API Key = فقط برای ارتباط اپ اندروید با API پنل
Cron Token  = فقط برای اجرای Refresh زمان‌بندی‌شده سرور
Admin Gate  = فقط برای باز کردن صفحه ورود مخفی مدیر

Cron Token و Admin Gate را هرگز داخل اپ اندروید، GitHub Repository یا کانال عمومی قرار ندهید.

صفحه نصب بعد از نصب با `installed.lock` غیرفعال می‌شود.

مرحله 5: ورود به پنل
---------------------
آدرس مخفی ورود در پایان نصب نمایش داده می‌شود و تقریباً این فرم را دارد:

https://YOUR-DOMAIN/YOUR-PATH/admin/login.php?gate=YOUR_ADMIN_GATE

بدون Gate معتبر، صفحه ورود برای بازدیدکننده عادی 404 نمایش می‌دهد.
ریشه سایت نیز عمداً محتوای عمومی معرفی VPN نمایش نمی‌دهد.

============================================================
بخش سوم — اضافه کردن لینک‌های VPN
============================================================

در پنل وارد «لینک‌های VPN» شوید.

برای هر منبع:
- نام بنویسید.
- Subscription URL خودتان را وارد کنید.
- Priority را مشخص کنید.
- Active را روشن بگذارید.
- ذخیره کنید.
- روی Refresh بزنید.

می‌توانید چند Subscription مختلف اضافه کنید.
Backend نودها را استخراج و Cache می‌کند؛ خود URL اصلی Subscription به اپ اندروید ارسال نمی‌شود.

پروتکل‌های اصلی قابل پردازش Backend شامل خانواده‌های رایج VLESS/VMess/Trojan/Shadowsocks و تعدادی پروتکل دیگر است؛ اپ فعلی اتصال VLESS/VMess/Trojan/Shadowsocks را هدف گرفته است.

============================================================
بخش چهارم — تبلیغات قبل از اتصال
============================================================

از منوی «تبلیغات» یک تبلیغ جدید بسازید:

- عنوان
- تصویر JPG / PNG / WebP / GIF
- لینک مقصد اختیاری
- زمان نمایش بر حسب ثانیه
- اولویت
- فعال/غیرفعال

در نسخه فعلی Android، اگر تبلیغ pre-connect فعال از API دریافت شود، قبل از اتصال نمایش داده می‌شود.
تفکیک کامل حساب رایگان/پولی و Login کاربر، ماژول جداگانه‌ای است و در این نسخه عمومی وجود ندارد.

============================================================
بخش پنجم — تنظیمات پنل
============================================================

در «تنظیمات اپ» می‌توانید:

- Base URL را بررسی کنید.
- مدت Cache Subscription را تغییر دهید.
- Minimum App Version را تنظیم کنید.
- Maintenance Mode را روشن/خاموش کنید.
- App API Key جدید بسازید.
- Cron Token جدید بسازید.
- Admin Gate جدید بسازید.

توجه:
اگر App API Key را عوض کنید، APKهایی که با کلید قبلی ساخته شده‌اند دیگر API را دریافت نمی‌کنند تا APK جدید با کلید جدید Build شود.

============================================================
بخش ششم — Cron برای Refresh خودکار
============================================================

Refresh هنگام درخواست API نیز می‌تواند انجام شود، اما برای کار بهتر Cron پیشنهاد می‌شود.

در cPanel → Cron Jobs مثلاً هر 10 دقیقه یک بار اجرا کنید.
روش URL با curl:

curl -fsS "https://YOUR-DOMAIN/YOUR-PATH/cron/refresh.php?token=YOUR_CRON_TOKEN" >/dev/null 2>&1

Cron Token را با مقدار واقعی خودتان جایگزین کنید.

اگر هاست اجرای PHP CLI را اجازه می‌دهد، می‌توانید فایل cron/refresh.php را مستقیم با PHP اجرا کنید؛ در حالت CLI توکن HTTP لازم نیست.

============================================================
بخش هفتم — آماده کردن پروژه Android در GitHub
============================================================

مرحله 1: ساخت Repository
------------------------
در GitHub یک Repository جدید بسازید.
مثلاً:
vpn-man-android

Private بودن برای توسعه شخصی بهتر است.
اگر Repository را Public می‌کنید، Secretها باز هم نباید داخل فایل‌ها Commit شوند.

مرحله 2: آپلود پروژه
---------------------
پوشه `02-vpn-man-android` را باز کنید.
**تمام محتویات داخل این پوشه** را در ریشه Repository آپلود کنید.

ساختار باید شبیه این باشد:

.github/
app/
scripts/
build.gradle.kts
gradle.properties
settings.gradle.kts
README.md

مهم:
پوشه `.github` مخفی است و باید حتماً آپلود شود؛ Workflow ساخت APK داخل آن قرار دارد.

مرحله 3: ساخت GitHub Secrets
----------------------------
در Repository بروید به:

Settings
→ Secrets and variables
→ Actions
→ New repository secret

دو Secret بسازید:

Secret اول:
Name: VPN_API_BASE_URL
Value: Base URL پنل شما

مثال:
https://vpn.example.com
یا:
https://example.com/vpn

بدون / آخر.

Secret دوم:
Name: VPN_APP_API_KEY
Value: همان App API Key که هنگام نصب VPN Panel ساختید.

Cron Token و Admin Gate را اینجا وارد نکنید.

============================================================
بخش هشتم — گرفتن APK از GitHub Actions
============================================================

پس از Upload/Commit معمولاً Build خودکار شروع می‌شود.
برای اجرای دستی:

Repository
→ Actions
→ Build Android APK
→ Run workflow

منتظر بمانید تمام مراحل سبز شوند.

پس از موفقیت، پایین صفحه Run قسمت Artifacts را پیدا کنید.
Artifact:

VPN-Man-Android-v1.0.2-arm64

آن را دانلود و ZIP را باز کنید.
داخل آن باید فایل زیر باشد:

VPN-Man-v1.0.2-arm64.apk

این Build برای arm64-v8a ساخته می‌شود تا حجم APK نسبت به Universal APK کمتر باشد.
اکثر گوشی‌های اندرویدی جدید arm64 هستند.
حداقل Android پروژه: Android 7.0 / API 24.

============================================================
بخش نهم — نصب و تست روی گوشی
============================================================

APK را روی گوشی منتقل و نصب کنید.
اگر Android اجازه نصب از منبع ناشناس خواست، فقط برای برنامه‌ای که APK را از آن باز کرده‌اید اجازه لازم را بدهید.

موارد تست:

1) اپ باز شود.
2) لیست سرورها از پنل دریافت شود.
3) Latency نمایش داده شود.
4) انتخاب سرور کار کند.
5) در صورت فعال بودن تبلیغ، قبل از اتصال نمایش داده شود.
6) Android درخواست مجوز VPN بدهد.
7) اتصال برقرار شود.
8) بعد از اتصال اینترنت از تونل عبور کند.
9) قطع اتصال از داخل اپ و Notification کار کند.

اگر یک نود خاص وصل نشد، ابتدا همان کانفیگ را در یک کلاینت معتبر دیگر تست کنید.
سرورهای VLESS بدون TLS/Reality امنیت پایین‌تری دارند؛ در سرویس جدید ترجیحاً TLS یا REALITY استفاده کنید.

بخش دوازدهم — نکات امنیتی مهم
============================================================

1) Subscription URLها را داخل سورس Android نگذارید.
2) App API Key را داخل GitHub Source Commit نکنید.
3) Admin Gate و Cron Token هرگز وارد APK نشوند.
4) حتماً HTTPS استفاده کنید.
5) رمز مدیر طولانی و یکتا انتخاب کنید.
6) Repository عمومی را مرتباً برای Secretهای لو رفته بررسی کنید.
7) App API Key هرچند از GitHub مخفی می‌ماند، در APK نهایی قابل استخراج است؛ برای سرویس عمومی بزرگ بهتر است سیستم Device Registration و Token کوتاه‌عمر اضافه شود.
8) برای سرور عمومی و پرترافیک Rate Limit/WAF/CDN و لاگ امنیتی جداگانه توصیه می‌شود.
9) مسیر نصب را از WordPress یا پروژه‌های دیگر جدا نگه دارید.
10) قبل از تغییرات مهم بکاپ بگیرید.

============================================================
بخش سیزدهم — رفع خطاهای رایج
============================================================

خطا: GitHub Actions Workflow دیده نمی‌شود
راه‌حل: مطمئن شوید `.github/workflows/build-apk.yml` در Repository وجود دارد.

خطا: Secret VPN_API_BASE_URL is missing
راه‌حل: Secret با همین نام دقیق بسازید.

خطا: Secret VPN_APP_API_KEY is missing
راه‌حل: App API Key پنل را به Repository Secret با همین نام اضافه کنید.

خطا: اپ می‌گوید آدرس API تنظیم نشده است
راه‌حل: APK را دوباره بعد از تعریف `VPN_API_BASE_URL` Build کنید.

خطا: 401 / unauthorized
راه‌حل: App API Key داخل GitHub با کلید فعلی پنل یکسان نیست.

خطا: هیچ سروری نمایش داده نمی‌شود
راه‌حل: داخل پنل Subscription را Refresh کنید و Last Error را بررسی کنید.

خطا: پنل بعد از نصب 404 می‌دهد
راه‌حل: برای ورود از URL حاوی Admin Gate استفاده کنید؛ Root و Login بدون Gate عمداً مخفی هستند.

خطا: سایت اصلی PHP/ionCube مشکل پیدا می‌کند
راه‌حل: پنل را روی ساب‌دامنه مستقل با PHP 8.1+ نصب کنید و PHP سایت اصلی را تغییر ندهید.
